📊 INSTALLER DÉTAILS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Ce que fait install.sh automatiquement :
• Vérifie l'environnement (Pi 400, architecture, Python)
• Installe ~16 dépendances système (FFmpeg, build-essential, etc)
• Crée l'environnement virtuel Python
• Installe 13 packages Python (numpy, pandas, moviepy, etc)
• Configure les répertoires (VIDEOS, SCRIPTS, VI, VIDEOS/SYNC)
• Crée les fichiers de config
• Teste tous les imports Python
• Veille FFmpeg
• Affiche un résumé final
• Prend ~45 min sur Pi 400
